One image summing up the world's news of Friday 20 November 2026: the cyclone that
hit Odisha at dawn, the overnight missile barrage over Kyiv, and the final day of
COP31 in Antalya — plus 43 more stories from seven regions, a UTC timeline of the
day as it broke, and a date check naming what was deliberately left out. See
[NEWS.md](NEWS.md) for the first-report date and source of every story.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) copies `entry.png` to `/output/entry.png`.
The image is deterministic: two runs produce the same bytes. No network access.

## About the image

46 stories, 7 regions. Three hero panels (Cyclone Akvan's landfall near Gopalpur,
the Kyiv barrage, COP31's closing day) and ten more illustrated stories, each
labelled in the image; a map with numbered pins 1–13; a six-number strip where
every figure is a 20 November event; and a DATE CHECK footer listing the big
19 November stories that were excluded on purpose. All thirteen illustrations
are original artwork made for this page.
